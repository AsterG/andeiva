# Code of conduct

Discuss technical work respectfully. Review ideas and code without attacking the
person proposing them. Contributors with different backgrounds and experience
levels should be able to participate safely.

Harassment, threats, discriminatory insults and disclosure of another person's
private information are not acceptable in issues, pull requests or other project
spaces. Do not post private reports or personal data as public evidence.

Maintainers may remove inappropriate content, request changes or restrict
participation to protect the community. Decisions should be proportionate and
explained to the people involved when doing so does not expose private information.

During private development, concerns go through the existing private project
channel. A verified community reporting contact must be established before public
contributions open.
