# Offline shared-reader profile conversion

Run `andeiva-preview grouped-profile` as the root installer only, after a fresh authorized `grouped-inspect` and successful `grouped-prepare`, with the legacy API and socket stopped. The package must provision the exclusive `andeiva-config-reader` group and its root-owned versioned registry. Resuming the legacy API changes its fingerprint: archive the known stale draft and prepare afresh; never rotate or edit a draft automatically.

The converter retains the real state checkpoint lock and all three reserve manifest locks. It changes only `grouped/state`, `grouped/admission`, `grouped/plan` and `grouped/emergency`: API ownership is preserved, reader group is assigned, directories become 02750, files become 0640, and the checkpoint lock remains 0600. Symlinks, ACLs, hardlinks, aliases, pending files, unexpected names, wrong ownership, changed bytes and changed directory identities are refused. Files are hashed through their retained descriptors before and after permission changes.

`/etc/andeiva-preview/grouped-profile.json` is created exclusively with root-only access. Version 1 contains `plan_sha256`, `prepared_sha256` and four `access` pins ordered state/admission/plan/emergency. Obtain `profiles`, `write_budget` and `local_origin` from the exact SHA-bound `grouped-prepared.json`; this output neither activates a runtime nor proves integrity or readiness. The actual capless helper identity must independently validate selected history and reserve banks before Boot and kernel readback.

An interrupted conversion is deliberately one-way and refused on retry. Preserve the partial destination and original source/backups for controlled recovery; do not repair permissions automatically. No source journal, original accounts, local boot stamp, network interface or active policy is changed.

Focused tests: `go test -race ./internal/previewruntime -run '^TestRoutedMigrationProfileV3' -count=1`. Native root-only qualification uses the compiled test binary with `-test.run '^TestRoutedMigrationProfileFaultsNativeV3$' -andeiva-native-migration-profile-faults-v3` for temporary permission/fault fixtures. The separate `TestRoutedMigrationProfileNativeV3` with `-andeiva-native-migration-profile-v3` converts the real fresh prepared destination and requires the offline conditions above. Neither opt-in is evidence until actually executed; ordinary skips are not qualification. Full helper G1 and activation remain separate gates.

The reader group must also have no primary members. Before conversion and before publishing, a bounded fixed getent passwd enumeration is required. NSS passwd/group providers are restricted to files/systemd; remote or unknown providers are refused because enumeration may be incomplete. No NSS configuration is changed.
